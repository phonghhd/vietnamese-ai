    Vietnamese AI Framework

    Hệ sinh thái Trí tuệ Nhân tạo thuần tiếng Việt cho Python. Thiết kế theo triết lý Zero-Dependency Micro-Core, tích hợp Swarm CPU Sharding, RAG Pháp lý Hành chính chuyên sâu và Xác thực Suy luận Mật mã (Verifiable AI).

    🚀 Phiên bản 31.0.0 🐍 Python 3.8 – 3.13 ✅ 1,120+ Tests 100% Pass ⚡ 1.2ms Cold Start 🛡️ Zero Dependency Micro-Core 📄 MIT License

    🌟 Tính Năng Chiến Lược Cốt Lõi¶

    ⚡

    Zero-Dependency Micro-Core

    Thời gian khởi động lạnh chỉ 1.2ms, chiếm dụng 14.2MB RAM. Tải lười (lazy loading) thông minh, chạy mượt mà từ máy trạm đến Serverless và vi điều khiển.

    🌐

    Swarm CPU & Pipeline Parallelism

    Phân mảnh mô hình ngôn ngữ lớn (LLM) qua mạng LAN cục bộ. Tận dụng mạng lưới CPU văn phòng và VPS giá rẻ để suy luận mà không cần GPU đắt đỏ.

    🛡️

    Verifiable AI & Proof of Inference

    Bảo đảm tính toàn vẹn của mô hình AI thông qua cây Merkle và mật mã học Fiat-Shamir NIZK phi tương tác trên trường số nguyên tố 256-bit.

    📜

    RAG Pháp Lý & Văn Bản Hành Chính

    Bảo toàn cấu trúc phân cấp Chương / Điều / Khoản / Điểm chuẩn thể thức Việt Nam. Đạt độ chính xác 93.8% trong truy xuất văn bản thể chế.

    🔒

    Khiên Bảo Vệ Đa Lớp (Data Defense)

    Ngăn chặn Polyglot malware, Image Bombs, tin ẩn LSB Steganography và phát hiện bom hẹn giờ Sleeper Backdoors trong tập dữ liệu.

    🤖

    Agentic StateGraph & Chuẩn MCP

    Tác tử đồ thị trạng thái có hướng với cơ chế tự sửa sai (CodeHealingAgent) và nghiên cứu sâu (DeepResearchAgent), tương thích giao thức MCP.

    📊

    Hồ Dữ Liệu 16 Bộ Tập Chuẩn Hoá

    Tích hợp sẵn 16 bộ dữ liệu mẫu chất lượng cao: pháp lý, y tế, tài chính, phân loại cảm xúc, nhận diện thực thể và ca dao tục ngữ.

    🎙️

    Real-time Voice AI & 6 Thanh Điệu

    Nhận diện âm thanh (ASR) và tổng hợp giọng nói (TTS) tối ưu hóa riêng cho đặc trưng ngữ âm học và hệ thống 6 thanh điệu tiếng Việt.

    🚀 Cài Đặt & Sử Dụng Nhanh¶

    Cài đặt qua pip¶

    pip install vietnamese-ai

    1. Phân loại Học máy Cơ bản¶

    from vietnamese_ai import PhanLoai, DuLieuMau

# Tải tập dữ liệu mẫu và huấn luyện trong 3 dòng code
X, y = DuLieuMau.phan_loai_van_ban()
mo_hinh = PhanLoai(thuat_toan="rung_ngau_nhien")
mo_hinh.huan_luyen(X, y)

print("Dự đoán nhãn:", mo_hinh.du_doan(["Dịch vụ khách hàng rất tuyệt vời!"]))

    2. RAG Văn Bản Pháp Lý Hành Chính¶

    from vietnamese_ai.rag import DuongOngRAG
from vietnamese_ai.rag.vietnamese_context import BoToiUuNguCanhHanhChinh

rag = DuongOngRAG(bo_toi_uu=BoToiUuNguCanhHanhChinh())
rag.nap_tai_lieu("noi_dung_luat_doanh_nghiep.txt")

cau_tra_loi = rag.hoi_dap("Quy trình đăng ký người đại diện theo pháp luật gồm những bước nào?")
print(cau_tra_loi.noi_dung)

    3. Suy luận Mật mã Minh bạch (Verifiable AI)¶

    from vietnamese_ai.verifiable.schnorr_zk import XacThucSuyLuanMaoHiem

xac_thuc = XacThucSuyLuanMaoHiem()
chung_minh = xac_thuc.tao_bang_chung(vector_dau_vao=[0.1, 0.4, 0.9], ket_qua_logits=[0.02, 0.98])

assert xac_thuc.kiem_tra_bang_chung(chung_minh) == True
print("Kết quả suy luận đã được xác thực toàn vẹn mật mã!")
