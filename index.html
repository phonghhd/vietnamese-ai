    Vietnamese AI Framework

    Hệ sinh thái Trí tuệ Nhân tạo thuần tiếng Việt cho Python. Thiết kế theo triết lý Zero-Dependency Micro-Core, tích hợp Kho tri thức `.vaidb`, RAG Pháp lý 100 điều khoản, Rà soát hợp đồng Redline, MCP IDE Server, Zalo/Telegram Connectors, Zero-GPU Edge LLM và Remote GPU Flywheel.

    🚀 Phiên bản 31.3.0 🐍 Python 3.8 – 3.14 ✅ 1,450+ Tests Passed 📦 349 Public APIs (.pyi) 🛡️ 0 Mypy / 0 Ruff Errors 📄 MIT License

    🌟 Tính Năng Chiến Lược Cốt Lõi¶

    ⚡

    Zero-Dependency Micro-Core

    Thời gian khởi động lạnh chỉ 24.68ms, chiếm dụng 12.82MB VmRSS trên CPU Celeron N3050. Tải lười (lazy loading) thông minh, chỉ phụ thuộc lõi NumPy.

    🌐

    Swarm CPU & Pipeline Parallelism

    Phân mảnh mô hình ngôn ngữ lớn (LLM) qua mạng LAN cục bộ. Tận dụng mạng lưới CPU văn phòng và VPS giá rẻ để suy luận mà không cần GPU đắt đỏ.

    🛡️

    Verifiable AI & Proof of Inference

    Bảo đảm tính toàn vẹn của mô hình AI thông qua cây Merkle và mật mã học Fiat-Shamir NIZK phi tương tác trên trường số nguyên tố 256-bit.

    📜

    RAG Pháp Lý & Văn Bản Hành Chính

    Bảo toàn cấu trúc phân cấp Chương / Điều / Khoản / Điểm chuẩn thể thức Việt Nam, hỗ trợ truy hồi theo mốc thời gian và kiểm chứng trích dẫn 3 tầng.

    🔒

    Khiên Bảo Vệ Đa Lớp (Data Defense)

    Ngăn chặn Polyglot malware, Image Bombs, tin ẩn LSB Steganography và phát hiện bom hẹn giờ Sleeper Backdoors trong tập dữ liệu.

    🤖

    Agentic StateGraph & Chuẩn MCP

    Tác tử đồ thị trạng thái có hướng với cơ chế tự sửa sai (CodeHealingAgent) và nghiên cứu sâu (DeepResearchAgent), tương thích giao thức MCP.

    📊

    Hồ Dữ Liệu 16 Bộ Tập Chuẩn Hoá

    Tích hợp sẵn 16 bộ dữ liệu mẫu chất lượng cao: pháp lý, y tế, tài chính, phân loại cảm xúc, nhận diện thực thể và ca dao tục ngữ.

    🎙️

    Real-time Voice AI & 6 Thanh Điệu

    Nhận diện âm thanh (ASR) và tổng hợp giọng nói (TTS) tối ưu hóa riêng cho đặc trưng ngữ âm học và hệ thống 6 thanh điệu tiếng Việt.

    📊 Kết Quả Đo Thực Tế Tái Lập (Direct Measurements — Zero-GPU CPU)¶

    Đo trực tiếp ngày 2026-11-27 trên máy văn phòng Intel Celeron N3050 @ 1.60 GHz (2 lõi CPU, 3.2 GiB RAM, không GPU), Linux x86_64, Python 3.14.4 qua lệnh vai benchmark --compare và vai benchmark --suite legal-temporal.

    Chỉ số Đo lường Giá trị Thực đo (v31.3.0) Phương pháp / Tập dữ liệu

    Tốc độ Tách từ Tiếng Việt (Rust Trie) 354,047 từ/s BoTachTuTiengVietSieuToc trên 100 điều khoản mở

    🚀 Cài Đặt & Sử Dụng Nhanh¶

    Cài đặt qua pip¶

    pip install vietnamese-ai

    1. Phân loại Học máy Cơ bản¶

    from vietnamese_ai import PhanLoai, DuLieuMau

# Tải tập dữ liệu mẫu và huấn luyện trong 3 dòng code
X, y = DuLieuMau.phan_loai_van_ban()
mo_hinh = PhanLoai(thuat_toan="rung_ngau_nhien")
mo_hinh.huan_luyen(X, y)

print("Dự đoán nhãn:", mo_hinh.du_doan(["Dịch vụ khách hàng rất tuyệt vời!"]))

    2. Kho Tri Thức .vaidb, RAG Pháp Lý & Rà Soát Hợp Đồng¶

    from vietnamese_ai import BoSoSanhRaSoatHopDong, DoThiThamChieuPhapLy, RAGPipeline

rag = RAGPipeline(
    backend="vaidb",
    duong_dan_vaidb="cong_ty.vaidb",
    che_do_nhung="onnx_viet",
    che_do_rerank="onnx_viet",
    che_do_hanh_chinh=True,
)
rag.them_tep("hop_dong_dat_dai.docx", che_do_hanh_chinh=True)
ket_qua = rag.hoi("Quyền chuyển nhượng sổ đỏ được quy định thế nào?")
print(ket_qua["tra_loi"])
rag.dong()

print(DoThiThamChieuPhapLy().truy_van_van_ban_lien_quan("45/2013/QH13", chi_lay_con_hieu_luc=True))
bao_cao = BoSoSanhRaSoatHopDong().so_sanh_va_ra_soat("hop_dong_doi_tac.docx", "hop_dong_chuan.docx")
print("Điểm an toàn:", bao_cao["diem_an_toan_phap_ly"], "| Rủi ro:", bao_cao["xep_loai_rui_ro"])

    3. Suy luận Mật mã Minh bạch & Bản đồ Minh bạch 3 Tầng¶

    from vietnamese_ai import KiemToanMatMa, bao_cao_ranh_gioi_he_thong

bao_cao = KiemToanMatMa.chay_kiem_toan_tu_dong()
assert bao_cao["tong_quan_dat"] is True
print(f"Đạt {bao_cao['so_hang_muc_dat']}/{bao_cao['tong_hang_muc']} hạng mục mật mã {bao_cao['chuan_mat_ma']}!")
print("Tổng quan 3 tầng:", bao_cao_ranh_gioi_he_thong()["tong_quan"])
